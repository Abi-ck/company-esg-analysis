# Corporate Performance & ESG Dashboard

## Project Overview
An interactive dashboard to analyze company financial performance and ESG indicators across industries, regions, and years. Developed with AI assistance using HTML, CSS, and JavaScript.

## Dataset
Includes company details, revenue, profit margin, market capitalization, growth rate, ESG scores, carbon emissions, water usage, and energy consumption.

## Key Features
- Interactive KPI cards and charts
- Year, industry, and region filters
- Company search
- Searchable data table
- CSV export and CSV/Excel upload

## Insights
The dashboard helps explore revenue trends, regional performance, industry ESG scores, environmental impact, and profit margin distribution.

## Conclusion
This project demonstrates data visualization, exploratory analysis, and interactive dashboard development to support data-driven decision-making.

## Tools
HTML, CSS, JavaScript, Plotly.js, Papa Parse, SheetJS, and AI assistance.
